# 项目介绍
这是一个用于洛克王国世界 PVP 的伤害计算器。

支持保存完整阵容信息，并模拟游戏中的技能、特性、天气等战斗机制。


目前已经同步至S4版本

优点:
- 快速计算是否可以斩杀,伤害结果足够精确
- 轻量快速，识别精灵和识别数字都是自己训练的模型，足够快速和轻量
- 不读取任何游戏文件
- 模拟游戏内的绝大部分效果
- 减少pvp成本学习

缺点:
- 需要玩家手动维护战斗数据 
- 图标需要自己爬取
- ui很差
- 为了追求精确计算，导致数字和框太多
- 部分特殊特性不支持（如银月狼王，加尔，彩虹独角兽的七个技能框）

## 简单使用
- 点击"精灵保存"->"阵容码" 将游戏阵容码导入，输入分组名
- 点击"队伍面板"->"插件模式"->[获取游戏窗口ID](#获取窗口ID)->点击"绑定窗口"->点击"混合模式"
- 开始前需要[校对识别框](#校对识别框)，分别为"战斗内框"和"战斗开始框"。战斗内框包含双方精灵图像识别框和血量框，以及我方技能威力框；战斗开始框为对战开始时敌方精灵阵容展示的六个精灵识别框
- 将保存的队伍导入左侧队伍分组
- ctrl+u识别敌方精灵后，可以使用ctrl+j进行快速计算。详细说明见插件模式

## 获取图像
[使用另一个项目](https://github.com/180sans/roco-icon-rawler)爬取并获取图标文件夹。图标独立存放在用户数据目录：

点击"界面配置", 点击"打开配置目录",将爬取的图像文件夹放入icons目录（需要新建目录）
```text
icons\
  pet\          精灵头像 PNG
  skill\        技能图标 PNG
  element\      属性图标 PNG
  skill_type\   技能类型图标 PNG
```

按原文件名放入对应文件夹后，重启程序即可显示。

新增精灵/技能图像时，将爬取输出目录更换为当前icons目录，进行爬取，会爬取缺失的图像

## 插件模式
- 需要获取并绑定[游戏窗口ID](#获取窗口ID)。本项目**不读取任何游戏文件**，采用视频验证是一样的
- 点击**混合模式**进入游戏和插件混合交互状态
- 蓝色边框固定为我方框，红色边框固定为敌方框
- 框可以自由拖动，调节大小。需要点击"更多"->"保存布局"来保存修改

### 快捷操作
- F8 编辑模式，可以回到插件,目前需要按windows后在点击F8才会起效
- F9完全收缩程序，目前需要按windows后在点击F9
- ctrl+j 快速计算，结果简单的出现在技能的右侧
- 伤害说明:
  - 在攻击方指定天分和性格的情况下，计算会出现三个伤害，代表着防御方的对应物防/魔防的"防御+"，"防御"，"防御-"
  - 在每个伤害对应两个百分比血量"生命++"和"生命+"，百分比向下取整，游戏内的百分比是向上取整的，所以**如果计算百分比大于当前血量百分比，一定可以击杀**
- ctrl+b 战斗开始识别，可用于战斗开始快捷导入敌方阵容
- ctrl+u 战斗内识别
- ctrl+p 校准威力（识别技能威力，对应位置的技能有叠层还会自动修正叠层，目前的模式不支持传动）
- ctrl+k 判断敌方精灵是否击杀自己，可以选择某个技能计算（不完善）
- ctrl+t 校对特性，通过技能威力来校对影响技能威力的特性，需要提前保证我方攻击buff正确
- ctrl+I/o 我方/敌方所有技能buff面板，用于快捷应用我方/敌方buff
- ctrl+Y 调整技能顺序，选择其他技能。主要用于处理传动和临时更换技能的情况

### 获取窗口ID

使用 PowerShell 命令获取窗口 ID（`MainWindowHandle` 下的数字）。

需要注意的是，会有两个窗口：一个是启动器窗口（launcher），另一个才是游戏窗口。

```powershell
Get-Process | Where-Object {$_.MainWindowTitle -like "*洛克王国*"} | Select-Object Id, ProcessName, MainWindowTitle, MainWindowHandle
```

### 校对识别框
- 有两类战斗相关窗口：

  - **战斗开始框**：包含 6 个敌方图像框，用于识别战斗开始时的敌方队伍。

### 框效果说明

- 队伍框: 导入已有分组
- 速度线框：查看双方速度分布。采用++，+，无，-来展示速度相应的天分和性格。数字框代表的是常规速度buff. 其中%是无法通过buff来增加的,因此无法手动调节，只做为展示
- buff框：点击后将展开详细的buff列表，出现buff后会在buff框中显式表现出来
- 萌化框：精灵的萌化buff，具有首领化的精灵可以点击"普通"来选择首领化
- 其他项框：奉献，愿力，星陨，雷暴都做了初版框架。但是目前愿力，星陨，雷暴不完善
- 天气框：目前只有雨天会影响战斗
- 醒目技能框：精灵保存界面运行你自由加入技能（比如倾斜），敌方精灵有该技能时会提醒出来

## 常规模式
已暂停更新

### 计算
- 支持常规计算，对于敌方天分无的情况会有一个预设来决定敌方天分和性格（预设为防御+， 防御，防御-.生命++，生命+，生命）
- 计算结果中"++"代表性格和天分双加成，"+"代表只有天分，"-"代表性格减益。 一般不会出现防御性格增益也不会出现生命减益，故默认防御没有++，生命没有-

### 阵容保存
- 保存技能,精灵，天分内容。可直接输入游戏内完整阵容码来进行快捷导入。
- 强烈建议保存自己的阵容所有数值，否则计算结果界面会有很多数值结果
- 可在队伍面板中直接导入以保存阵容

### 战斗相关特性
- 实现绝大部分的战斗相关特性
- 如特殊条件类，如星光狮，鸭吉吉（需要点击触发按钮）
- 部分特性为被动（如泥吼呀，独角兽），会自动结算
- 叠层特性可以手动输入层数
- 保存界面可以指定是否默认触发（针对巨噬针鼹），首领化，以及叠加层数（针对蜂后）

### 技能触发情况
- 特殊触发技能的计算结果中会带有两种情况的展示，触发情况和基础情况
- 可叠层特性需要自己输入层数（如果不知道自己叠了几层，可以点击计算结果来看威力和游戏内是否一致）

### 首领化和萌化
- 首领化针对棋绮后做了特殊处理，不会替换原本的特性

### buff类技能快速叠加
- 如嘲弄等叠buff技能可以直接快速应用，会给相应目标对应的buff(目前标签不完善)

### 其他功能
#### 天气
- 目前只有雨天对战斗有影响

#### 奉献
- 目前有奉献的威力增加+以及连击加成

#### 雷暴
- 雷暴面板中有选用的技能，选择后代表雷暴目前已经记录这个技能
- 战斗中，如果电流刺激特性触发并且（星光狮特性）没有记录在雷暴面板，两次雷暴（面板中有电流脉冲）伤害会不一致，这点和游戏一致

#### 印记
- 给敌方设置星陨印记层数在引爆时会自动星陨印记的伤害（目前伤害未分离）
- 对应的支持蓄势印记，蓄电印记（需要手动点击触发），攻击印记
